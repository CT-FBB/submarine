## ✨ Features

| Feature | Description |
|---|---|
| 🌐 **3D Globe** | Dark-theme rotating earth with lat/lon grid |
| 🗺️ **Asian Coastlines** | Simplified coastline outlines for context |
| 🔵 **Main Trunk** | Glowing cyan arcs: SG → HK → Taiwan → Korea → Japan |
| 🟠 **Branch Cables** | Orange arcs to Thailand, Cambodia, Vietnam, China |
| 💛 **Data Flow** | Animated yellow pulses flowing along cables |
| 📍 **Landing Stations** | 10 pulsing markers with country flags and labels |
| ⭐ **Starfield** | Twinkling background stars |
| 📊 **HUD Stats** | Animated counters: 10,500 km · 144 Tbps · 8 FPs · 11 Landings · 9 Countries |
| 🖱️ **Interactive** | Drag to rotate · Scroll to zoom · Hover for details |
| 📱 **Mobile** | Touch-friendly with responsive layout |
